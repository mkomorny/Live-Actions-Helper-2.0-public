3. Component Rules for Claude Replication

A. Top HUD Navigation

- Height: 56px, pinned to top.
- Left: 32x32px gradient logo badge ("LA") + App title + subtitle.
- Center: Segmented capsule pill selector for view switching.
- Right: Live telemetry capsule (BPM, Key, Status dot pulse).

B. Left Target Tracks Sidebar

- Width: 280px fixed width.
- Header: Quick selector pills ("ALL", "NONE", "LIVE SEL").
- Cards: Track name, Live API path ("live_set tracks 0"), 4px color strip, type badge (MIDI/AUDIO).
- Active state: cyan glow border + cyan highlight background.

C. Action Execution Buttons

- Primary Run Button: linear-gradient(135deg, #06b6d4, #8b5cf6), 800 font weight, 10px 28px padding.
- Ghost Button: rgba(255, 255, 255, 0.06) background + 1px border.
- Last Result banner: Emerald accent with "Open Folder ↗" shortcut.
