# User Manuals — music / music-software only

Genius uses **this tree for music and music software**. Skip AI docs and Windows-developer docs unless the ask is actually those topics.

Root: `B:\Documents\TRAINING DOCS\User Manuals\`

Open **1–3** books. Prefer a child index when one exists.

---

## In scope (music / music software)

| Area | Path | Open when |
| --- | --- | --- |
| Live 12 chapters | `Ableton\Ableton Live 12 Standard Manual\INDEX.md` | any Live how-to |
| Live 12 full PDF | `Ableton\live12-manual-en.pdf` | ch. 30 instruments; anything missing from the split |
| Max for Live | `Ableton\Max for Live\` | Max, LOM, JS, Node for Max, M4L devices |
| Ableton Note | `Ableton\Note\` | Note app, Capture, samples, Link, presets |
| Live skins | `Ableton\Guide for Creating Ableton Live Skins.pdf` | Live themes |
| Launchkey MK4 61 | `Novation\INDEX.md` | keys, pads, Zones, Arp, Components, DAW control |
| Novation Play / STACKS / GLAZE | `Novation\novation-play-guide.pdf` · `STACKS - Browser.pdf` · `STACKS - Sound Editor.pdf` · `GLAZE - Snapshots.pdf` | those products |
| Plugin + hardware books | `Other Manuals\` + master INDEX **Third-party plugins** table | named plugin |
| Producer Pal / Genius how-to | `Other Manuals\Producer Pal Genius User Manual.pdf` · `producer-pal-ai-readable-guide.pdf` | Pal itself |
| Session I/O | `Other Manuals\M-Track Duo - User Guide - v1.5.pdf` · `Other Manuals\Dolby Atmos for Win Config Guide.pdf` · `Windows\MIDI Services\` | interface, Atmos, Windows MIDI |
| Google Flow **music** | `AI\Google\google-flow-music-guide.pdf` | only if they asked about Flow music |

`Other Manuals\` in this folder is music software (Ozone, Massive, Helm, Surge, Komplete, Oberheim, Replika, Røverb, Schema, Slammer, Tape Suite, TRK-01, LUXE, FEEL IT, Clipper, MOD PACK, Axxess, Bass Station, Phasis, Driver Manual if it is an audio driver). Plugin aliases live on the master INDEX so they are not duplicated here.
