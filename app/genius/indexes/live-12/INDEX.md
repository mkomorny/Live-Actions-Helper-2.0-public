## Pal vs the book

Producer Pal / Live Actions Genius can create/read/update tracks, scenes, clips, **native** Live devices, routing, mixer, library search, and playback. Already-present VST/AU: Live Actions Genius may inspect and set **LOM-visible** knobs (`live_inspect_plugin` / `live_read_device` / `live_update_device`). **Cannot** add VST/AU plugins, trigger stem separation, or write automation / clip envelopes.
