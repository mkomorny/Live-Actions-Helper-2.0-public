App Changes Tracker Instructions

This tracker is the permanent historical changelog for the Live Actions Helper project only. It records every version, release date, change description, and GitHub repository/tag link for this repo — nothing else. Mandatory Live Actions Tool Building Rules & Guardrails

1. Append-Only Guarantee Never edit, rewrite, or remove a prior version entry in this tracker. The historical log is permanent.
2. Live 12 Standard Only The target is Ableton Live 12 Standard, not Suite. Never use native right-click Extensions or Suite-only APIs.
3. Device Protection Never modify official Max for Live devices (Producer_Pal.amxd). All features use bridge tools (live_*).
4. Settings Location User settings & API keys live in %APPDATA%\Live Actions\settings.json. Never commit secrets to the repo.
5. Semantic Versioning Determine the next version from the latest git tag (git describe --tags --abbrev=0). Tag format: vX.Y.Z.
6. Mandatory 9-Step Pass Docs Review → Implement → Next Version → Update Plan → Append Tracker → README → Dev Notes → Commit & Tag → Push & Cleanup.
